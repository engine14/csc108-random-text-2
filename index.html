Why a tuple and not a list?

Dictionary keys must be values that cannot change. A list can change, so Python refuses it as a key. A tuple cannot change, so it works. Run the code and read the error, then fix it.

A new dictionary method called setdefault

  

    

      
Last class, adding a word to a key's list took two steps, because the list might not exist yet.

      
if key not in d:    d[key] = []d[key].append(value)

      
d.setdefault(key, default) does the first two lines in one call. If key is already in d, it returns d[key]. If it is not, it stores d[key] = default first, then returns it. Either way you get back the list that is inside the dictionary, so you can append to it right away.

      
d.setdefault(key, []).append(value)

      
The two versions do exactly the same thing. Use whichever you find clearer. associate_pair in today's starter code uses setdefault.
